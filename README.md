## 📚 Overview
This repository documents my participation in the **AI Agents Intensive Course with Google**, a 5-day interactive program hosted on **Kaggle** and supported by **Google AI**, **NVIDIA**, and **Cohere**.

Each day includes:
- Whitepapers, podcasts, and codelabs released via Kaggle.  
- Live sessions with Google researchers and partner engineers.  
- Collaborative discussions and Q&A on Discord.  
- Optional **capstone project** — building a custom AI agent using the course stack.

---

## 🗓️ Schedule
| Day | Focus | Resources |
|:----|:------|:-----------|
| **Day 1 – Foundations** | Introduction to AI Agents & tool-use frameworks | Kaggle Course Page, Discord #5dgai-announcements |
| **Day 2 – LLM Toolchains** | Prompt design, planning & memory | Codelab + Whitepaper |
| **Day 3 – APIs & Integration** | Using AI Studio API + external data APIs | Codelab + Podcast |
| **Day 4 – Evaluation & Safety** | Testing agents for reliability, bias & guardrails | Livestream + Resources |
| **Day 5 – Capstone** | Build & deploy your own agent | Kaggle Badge Project |

> 🕐 Daily livestreams at **11 AM PT / 8 PM CET / 12:30 AM IST** on Kaggle YouTube.

## 🧰 Setup

### 1. Kaggle
- Create / verify a Kaggle account.  
- Learn basic Notebook operations and enable phone verification (required for codelabs).

### 2. AI Studio
- Sign up and generate your **API key** for agent experiments.

### 3. Discord
Join the [Kaggle Discord](https://discord.gg/kaggle) and visit:
- `#5dgai-announcements` — official updates  
- `#5dgai-introductions` — meet participants  
- `#5dgai-question-forum` — ask & discuss  
- `#5dgai-general-chat` — open conversation  

Link your Kaggle account to Discord → [confirmation link](https://kaggle.com/discord/confirmation).
